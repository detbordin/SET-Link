SET Link — รับ/ส่งข้อมูลกล้อง Sokkia SET

สำหรับ SET630RK และรุ่น Series 30R · ใช้กับ Chrome / Edge บน Windows 11 หรือ Chrome บน Android

ยังไม่เชื่อมต่อ รับ 0 ไบต์ ส่ง 0 ไบต์ ⏸ กล้องสั่งหยุดชั่วคราว (XOFF)

ตั้งค่าการสื่อสาร (ต้องตรงกับในกล้อง)

ดูค่าในกล้องที่ CNFG → Comms setup แล้วตั้งให้ตรงกันทุกช่อง · Check sum ในกล้องให้ตั้งเป็น No

เลือกวิธีเชื่อมต่อ

USB โดยตรง — มีไดรเวอร์ในตัวสำหรับชิป Prolific PL2303, CH340/CH341, FTDI และ CP210x ใช้ได้แม้ Windows 11 ขึ้นว่าไดรเวอร์ไม่รองรับ (บน Windows ต้องเปลี่ยนไดรเวอร์สายเป็น WinUSB ด้วย Zadig ครั้งเดียว · บน Android เสียบผ่าน OTG ใช้ได้เลย) ดูขั้นตอนในแท็บ “วิธีใช้”
COM port — ใช้เมื่อสายขึ้นเป็น COM ใน Device Manager ได้ปกติ

ทำไมสายเดิมใช้กับ Windows 11 ไม่ได้

      
สายแปลง USB→RS-232 ที่ขายคู่กล้องส่วนใหญ่ใช้ชิป Prolific PL2303 รุ่นเก่า (HXA/XA) ซึ่ง Prolific เลิกทำไดรเวอร์ให้แล้ว
        พอเสียบใน Windows 11 จะขึ้นเครื่องหมายตกใจ, Code 10 หรือ “PHASED OUT SINCE 2012” ตัวสายไม่ได้เสีย แค่ไม่มีไดรเวอร์
        เครื่องมือนี้จึงคุยกับชิปในสายโดยตรงแทนไดรเวอร์

      
เช็กชิปของสาย: Device Manager → คลิกขวาที่สาย → Properties → Details → Hardware Ids
        · VID_067B = Prolific · VID_1A86 = CH340 · VID_0403 = FTDI · VID_10C4 = CP210x

    


    

      
วิธี A — คอม Windows 11 (แนะนำ)

      
    
        
  1. ดาวน์โหลดโปรแกรม Zadig จาก zadig.akeo.ie (ไม่ต้องติดตั้ง)
    2. 
        
  2. เสียบสาย เปิด Zadig → เมนู Options → List All Devices
    3. 
        
  3. เลือกรายการของสาย (เช่น “USB-Serial Controller” หรือที่มี USB ID 067B)
    4. 
        
  4. ช่องขวาเลือก WinUSB → กด Replace Driver รอจนเสร็จ (ทำครั้งเดียว)
    5. 
        
  5. เปิดหน้านี้ด้วย Chrome หรือ Edge → แท็บ 1 → กด USB โดยตรง → เลือกสายในหน้าต่างที่เด้งขึ้น
    6. 
      

      
หลังเปลี่ยนเป็น WinUSB สายนี้จะไม่ขึ้นเป็น COM port สำหรับโปรแกรมอื่น
        ถ้าอยากเปลี่ยนกลับ: Device Manager → คลิกขวาที่สาย → Uninstall device → ติ๊ก “Delete the driver” → ถอดเสียบใหม่

    


    

      
วิธี B — มือถือ Android (ไม่ต้องลงไดรเวอร์เลย)

      
    
        
  1. เสียบสายเข้ามือถือผ่านหัวแปลง USB OTG
    2. 
        
  2. เปิดหน้านี้ด้วย Chrome (ต้องเป็นลิงก์ https เช่นอัปขึ้น Netlify)
    3. 
        
  3. แท็บ 1 → USB โดยตรง → อนุญาตการเข้าถึงอุปกรณ์
    4. 
      

    


    

      
ถ้ารับมาแล้วเป็นตัวอักษรเพี้ยน / ไม่มีอะไรเข้ามา

      
    
        
  • ตัวอักษรมั่ว ๆ = Baud rate ไม่ตรงกับในกล้อง ลองเปลี่ยนให้ตรง (ตัดการเชื่อมต่อแล้วต่อใหม่)
    • 
        
  • ไม่มีข้อมูลเลย = ตรวจหัวต่อสายกับกล้องให้แน่น, เปิด Check sum = No, ลองสลับ Xon/Xoff ทั้งสองฝั่งให้ตรงกัน
    • 
        
  • ส่งพิกัดแล้วกล้องขึ้น Receiving 0 = ลองรับข้อมูลจากกล้องก่อน ถ้ารับไม่ได้แปลว่าสาย/ค่าการสื่อสารยังไม่ตรง · ถ้ารับได้ ให้ลองทีละอย่าง: ติ๊ก “ใส่บรรทัดหัวไฟล์”, ตั้ง Xon/Xoff = No ทั้งสองฝั่ง, ท้ายบรรทัดเป็น CR อย่างเดียว, เปลี่ยนเป็น SDR2x (เลขจุด 1–4 หลัก), เพิ่มหน่วงเป็น 300 ms และดู “บันทึกการทำงาน” ว่ากล้องตอบอะไรกลับมา
    • 
        
  • หมายเหตุจากคู่มือกล้อง: จุด Known data ที่รับมาทางสาย จะไม่ถูกส่งออกตอนดาวน์โหลด JOB
